\section{Incremental range precision and recall}
The same workload analysis also exposes a different repeated-scan problem.
Tatbul range precision and recall score predicted intervals rather than only
points~\cite{tatbul2018}. TimeSeAD already maximizes the classic range F-score
over every observed score threshold~\cite{timeseadclassic}. Its pinned implementation
reconstructs predictions and interval statistics at each threshold. Thus our
question is not whether exhaustive evaluation is possible, but whether those
statistics require repeated full-array scans.

\paragraph{Target.}
Here predictions use the public range-F1 convention $p_i(t)=\ind\{s_i>t\}$,
distinct from the VUS convention above. Let $T_j$ be the $K$ true intervals and
$C_\ell$ the $J$ current predicted intervals. Write $m_j=|T_j\cap P|$ and $r_j$
for the number of predicted intervals intersecting $T_j$. For a predicted
interval $C$, write $u(C)=|C\cap Y|$ and $h(C)$ for the number of true intervals
intersecting it. Flat positional weights and reciprocal cardinality give
\begin{align}
 R_\alpha&=\frac1K\sum_j\left[\alpha\ind\{m_j>0\}
 +(1-\alpha)\frac{m_j}{|T_j|r_j}\right],\\
 P_r&=\frac1J\sum_C\frac{u(C)}{|C|h(C)},\qquad
 F_1=\frac{2P_rR_\alpha}{P_r+R_\alpha}.
\end{align}
Zero-overlap terms and empty outer collections contribute zero. These
conventions, positional weights and cardinality are explicit; the algorithm
does not cover every customization of the metric. Our primary target has
$\alpha=.2$. The unchanged TimeSeAD classic comparison uses $\alpha=0$ instead.

\begin{proposition}[Local range-statistic updates]
After fixed-label preprocessing, inserting one predicted-positive position
changes at most one true interval's recall statistics and at most three
predicted-component terms in the precision sum. On a one-dimensional path,
these changes can be maintained in constant time per insertion.
\end{proposition}
\begin{proof}
If position $i$ lies in true interval $T_j$, increment $m_j$ and change $r_j$ by
\[
 1-\ind\{i-1\text{ active in }T_j\}
  -\ind\{i+1\text{ active in }T_j\}.
\]
Replace only this interval's overlap term and add its existence reward on its
first hit. If $i$ is outside every true interval, it cannot connect two
fragments inside one contiguous $T_j$, so recall statistics stay unchanged.
For precision, subtract each existing adjacent component's contribution and
add the merged interval's contribution. Prefix counts of true points and true
interval starts recover $u(C)$ and $h(C)$ in constant time, including a true
interval already in progress at the left boundary. Finally, an active neighbor
of an inactive point must be a current component endpoint. Arrays storing the
left boundary at each right endpoint and the right boundary at each left
endpoint therefore identify both adjacent components without disjoint-set
search. Update only the new outer endpoints. Interior stale entries are never
queried. Each insertion performs constant work.
\end{proof}

\paragraph{Queries and complexity.}
Sort scores and queries in descending order, activate every point strictly
above each query, and emit a state only after all eligible ties. For $H$ ordered
queries this costs $O(n\log(n+1)+n+H)$ time and $O(n+H)$ space. Query sorting,
when required, adds $O(H\log(H+1))$. With a small known query set, full score
sorting is unnecessary: binary search each score among ordered queries to
find its first strictly eligible query, then counting-bucket its activation.
This gives $O(n\log(H+1)+n+H)$ for ordered queries, with the same extra sorting
term for arbitrary query order. Points within a bucket can activate in any
order because no intermediate state is returned. These are ordinary sorting
and offline query techniques, not newly invented data structures.

The contribution is the metric-specific local sufficient statistics.
Descending connected level sets and component trees are classical, including
general-graph union-find constructions~\cite{najman2006}; the one-dimensional
endpoint simplification is elementary. Unlike the VUS reduction, this operator
cannot discard off-label events. For example, with $y=(1,0,1)$, changing the
prediction from $(1,0,1)$ to $(1,1,1)$ leaves recall one but changes precision
from one to $1/3$. Recall itself need not be monotone under insertions because
an extra fragment can increase its cardinality penalty. Neither support-only
activation nor a monotone-recall shortcut is used.

\paragraph{Exactness and boundary conventions.}
The identities hold in real arithmetic for real binary64 score comparisons.
Numerical sums use compensated accumulation; a length-independent rounding
certificate and bitwise agreement are not claimed. The research API's
experimental contract is finite real binary64 inputs; coercion of complex or
large exact-integer inputs is outside that contract. The strict observed-score
query set excludes the all-active state below the minimum, so its maximum is
not an unrestricted optimum over all masks. The code supports a lower sentinel
when that state is requested. A separate compatibility option reproduces the
pinned TSB-AD all-one parser convention; ordinary interval semantics remain the
mathematical default.
