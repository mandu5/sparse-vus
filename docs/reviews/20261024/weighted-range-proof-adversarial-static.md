# Weighted range theorem: adversarial static audit

Audit date: 24 October 2026. Scope: `paper/weighted_range_method.tex`, the current `src/sparse_vus/weighted_range.py`, the finite-grid ordering helper, and `src/sparse_vus/timeeval_adapter.py`. This pass read text and source only. It ran no numerical code, tests, TeX, or benchmarks during the Mac native timing window. Earlier numerical evidence belongs to the separately recorded proof/feasibility notes.

**Result: no major correctness blocker found under the theorem's stated assumptions.** The strongest remaining mathematical caveat is the explicitly conditional arithmetic model, not a failed local-update argument. The generic interface is not implemented. Two small clarifications would make the short proof harder to misread.

## Clarifications worth incorporating

1. **Make interval ownership explicit.** At method lines 61–66, add: “An owner array, built in `O(n)` time, identifies the true interval containing each point.” Otherwise the phrase “inserting `i` in `T_j`” leaves its lookup cost implicit. The implementation already constructs `ids` in lines 176–177; this is a proof exposition gap, not missing implementation or a changed bound.
2. **State precisely what constant-cost gamma means.** Lines 30–31 and 56 assume constant-cost local gamma and unit-cost exact arithmetic. That makes the conditional theorem valid. However, the implemented improved factor is not an `O(1)` exact rational computation under a model that supplies only addition, subtraction, multiplication, and division: general exponentiation requires additional operations, and exact output bit lengths can grow. Suggested wording: “The bounds count arithmetic operations and assume the stated coefficient and cardinality evaluation costs; they are not bit-complexity bounds.” An exact gamma oracle or an expressly charged elementary-function primitive is consistent with the theorem. Floating `exp/log1p` is its numerical implementation, not a proof of exact primitive evaluation. The longer proof note already states this boundary.

Neither clarification changes the recurrence, asymptotic bound under its assumptions, or implemented family. I have not edited the manuscript section in this audit.

## Adversarial proof checks

| Potential failure | Static resolution |
|---|---|
| An insertion outside all true intervals changes a distant interval's fragmentation count. | Impossible for disjoint maximal binary-label intervals on a line. Two active fragments inside one `T_j` can connect only through positions inside `T_j`. An off-label bridge can join components intersecting different true intervals without changing either interval's restricted active runs. |
| Both neighboring active points belong to the same component, so subtracting two contributions is wrong. | An inactive point separates the two neighbors on a one-dimensional path. If both are active, they belong to distinct components. This would fail on a graph with alternate paths; the theorem does not cover that setting. |
| Stale interior boundary entries are read after a merge. | Every active neighbor of the currently inactive point is an outer endpoint. Only these entries are read, and every insertion updates the new outer entries. Implementation lines 116–123 and 135 match this invariant. |
| Zero positional weight makes detection existence disappear. | The mathematical definition uses positive overlap count, not positive weighted mass, for existence. The short proof explicitly retains this distinction. The implementation's canonical weights are strictly positive, while the general theorem permits zeros. |
| Endpoint-dependent precision weights require touching all points in the merged component. | A component is fully active. Its numerator therefore depends on fixed labels and its endpoints, so fixed labeled feature prefixes evaluate it. The normalizer uses the corresponding unlabeled prefixes. The partition and coefficient cost assumptions are essential. |
| The number of intersected true intervals is not a prefix statistic when the component starts inside an interval. | The correction `y_a - sigma_a` counts exactly that interval; starts inside `[a,b]` count all others. `_component` implements the same correction in lines 59–60. |
| Recall preprocessing secretly costs more than `O(qdn)`. | True intervals are disjoint and number at most `n`. Generate one interval's coefficients, compute its normalizer, and evaluate its fixed point weights; summing these costs is bounded by `O(qdn)`. One coefficient list suffices as scratch. No coefficient table per active component is required. |
| Arbitrary within-bucket order invalidates the sweep. | The invariant is proved after any insertion sequence. The first-eligible-query bins are ordered; before each emitted query their union is exactly `{i:s_i>t}`. Distinct score levels within one bin may be inserted in any order because no intermediate state is emitted. This is exact-arithmetic path independence, not bitwise floating-order independence. |
| Sorting by recall is assumed free or recall is assumed monotone. | Lines 104–108 charge the consumer's recall sort and explicitly reject monotonicity. An already ordered query grid only removes query sorting, not downstream curve sorting. |
| Empty truth or prediction divides by zero. | The target explicitly defines empty averages as zero. When truth is empty every precision numerator is zero, so the implementation's early all-zero return is consistent. |

The finite-feature theorem needs fixed endpoint-independent features, fixed configuration, nonnegative finite positional weights with positive normalizers, an explicit finite partition, and pure local cardinality/aggregation functions with the stated costs. Arbitrary mask-dependent callbacks, overlapping labeled event objects, graph-connected components, and unrestricted partition discovery are outside this proof. The section's current restrictions are sufficient; weakening them would require a different argument.

## Implementation and source boundary

The four normalizers match direct summation and the pinned TimeSeAD implementation: flat `L`, front/back `L(L+1)/2`, and middle `floor((L+1)^2/4)`. Middle uses two first-moment queries with the midpoint assigned consistently for odd and even lengths. The source's reciprocal and improved factors match the mathematical definitions; the `count=1` branch handles the length-one case. [TimeSeAD positional and cardinality source](https://github.com/wagner-d/TimeSeAD/blob/bb8efa9ce17f9cfb0bab77df08c32d986de8429e/timesead/evaluation/ts_precision_recall.py)

The signed-int64 restriction is sufficient for canonical numerator and normalizer arithmetic: first moments are at most `n(n-1)/2`, linear normalizer products are at most `n(n+1)`, and a loose bound of `2n^2` covers the combined midpoint expression. All are below `2^63-1` at `n <= 2^31-1`. This is an analytic bound, not a giant-array execution or a bound for arbitrary polynomial degrees. Division, `exp/log1p`, and compensated global sums still round. The current section correctly declines bitwise equivalence and a uniform floating-point error certificate.

TimeEval's native default consumer is narrower than the theorem and kernel: flat bias, zero existence weight, and cardinality one. The adapter explicitly rejects the optional reciprocal/default-constructor alternative. Its class-balance all-active endpoint is therefore mathematically appropriate even with multiple true intervals; it must not be described as a corrected native endpoint. Source threshold sampling, recall/precision sorting, and synthetic terminal points remain consumer conventions. Native parity evidence for this consumer cannot establish the whole four-bias/three-cardinality family. [Pinned TimeEval range-curve source](https://github.com/TimeEval/TimeEval/blob/7c3622757b1a3afa9a84cbc97ce132d9e379f715/timeeval/metrics/range_metrics.py#L228-L296)

Tatbul's closed-form overlaps and sorted interval processing, and classical one-dimensional component trees with attributes, remain material antecedents. The proof establishes a particular coupled, label-conditioned state and its cost; it does not establish global novelty, a new metric, a new tree construction, or universal practical benefit. The recent-primary-source screen and citations remain in `weighted-range-proof-and-novelty.md`. [Tatbul et al., Section 5.5](https://papers.nips.cc/paper_files/paper/2018/file/8f468c873a32bb0619eaeb2050ba45d1-Paper.pdf), [Menotti et al., Sections 3.3–3.4](http://urlib.net/dpi.inpe.br/ismm@80/2007/03.10.10.19)

## What this audit does not establish

This is an independent static proof/implementation comparison. It does not replace clean-host execution, consumer output audits, performance confidence intervals, or a proof of numerical stability. Existing test text includes an independent `Fraction` oracle, mixed biases and aggregations, off-label merges, ties, midpoint distinctions, large coordinate offsets, a high-precision improved-gamma regression, and native consumer plateau cases. Their presence was inspected; their execution status was not revalidated in this pass. The theorem-only engine would need its own direct-sum tests if later implemented.
