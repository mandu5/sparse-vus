# MSAD published-score corpus acquisition design, 2026-10-23

This protocol is fixed before any new VUS or ranking outcome. It acquires the original stored scores from the authors' [VLDB 2023 MSAD repository](https://github.com/boniolp/MSAD/tree/8141b94eb3d2b1811f81ffcf7bc8aa5dcbd6c204), whose README links [TSB.zip](https://drive.google.com/file/d/1PQKwu5lZTnTmsmms1ipko9KF712Oc5DE/view). The HEAD length observed on 2026-10-23 is 841,275,484 bytes. Its ZIP central directory contains 26,354 entries; 1,895 raw-series keys have all twelve stored detector score members. Excluding `.train.` filenames and raw members larger than 12,000,000 uncompressed bytes leaves 1,863 candidates in 16 source families. These are metadata eligibility counts, not validated numerical cases.

The complete model list is AE, CNN, HBOS, IFOREST, IFOREST1, LOF, LSTM, MP, NORMA, OCSVM, PCA, POLY. IFOREST1 is retained as a separately named published configuration, not advertised as a thirteenth/new detector algorithm. There is no inference, score smoothing, rescaling, quantization, zero padding, or imputation. Official text precision is preserved when parsed to binary64. A two-member format probe observed quantized AE scores before protocol freeze; no VUS or ranking statistic was evaluated.

Within each source family order candidates by SHA256 of the UTF-8 string `msad-vus-20261023-v1\0` followed by `family/filename`. Visit candidates in sorted-family round-robin order, retaining the first 128 valid and duplicate-free cases. A candidate must have two binary classes, finite one-dimensional observations, and twelve finite one-dimensional score arrays exactly matching the raw row count. Invalid cases are logged and only replaced from this fixed queue. A case is excluded before metric evaluation if its canonical label-array hash or observation hash matches any of the prior 350 TSB-AD series, the prior 12 mTSBench series (including individual observation columns), or an earlier retained case. Observation checks include exact binary64 arrays and standardized arrays rounded to ten decimal places; this intentionally conservative filter can exclude distinct data with identical label patterns. It does not prove absence of all possible cropped or transformed overlaps. Family/source overlap is explicitly retained and reported; this is a new input/score workload, not a claim of entirely unseen domains or source families. The initial 128 metadata candidates require 96,402,984 compressed payload bytes (before duplicate exclusions), excluding range-header overhead.

Every ZIP member is read through bounded HTTP byte ranges, validated against central-directory method/length/name/CRC, and SHA256 recorded. Fail closed if exact Range responses are not honored; do not silently download the entire archive. Metadata and the candidate queue are frozen before data acquisition. Source files and prior manifests are hash-bound. Raw observations, labels, stored scores, and NPZ arrays remain in the ignored cache. The repository's MIT code license is not asserted to license third-party datasets; individual source licenses have not been consolidated here. Public outputs are acquisition/identity metadata and provenance receipts only. The MSAD paper and source data authors retain attribution. No VUS function is imported by the acquisition script.

The new output directory is `artifacts/msad-corpus-20261023`; raw members and arrays are under `.cache/msad-corpus-20261023`. A completed manifest exposes `series` rows containing `npz_path`, `npz_sha256`, `family`, `series`, `n`, `positive_points`, `array_sha256`, and original member receipts. Each NPZ contains `observations`, `labels`, and the twelve exact model-name arrays above. Benchmarking must freeze its separate method/width/reporting protocol before reading metric results.

Acquisition stops rather than silently exceeding 500,000,000 downloaded response bytes. An interruption or unusable member is retained in an append-only attempt log. No incomplete corpus is presented as complete, and no scientific effect size is inferred from successful acquisition.
