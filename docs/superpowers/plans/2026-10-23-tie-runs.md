# Tie-run research extension

Goal: remove the position-by-position cost of large numerical ties for one
original anomaly interval, while certifying early termination using integers.
This is a new research extension; all 21 October protocols and results remain
frozen. The user authorized continued design, implementation and experiments.

Design decisions:
- Preserve complete global binary64 ties and the original dynamic VUS target.
- Group maximum-support positions by score and contiguous temporal runs.
- Activate score groups at their nearest distance; reuse reverse-list insertion.
- Sum ramp masses by differences of exact three-limb fixed-point prefixes of
  rounded square roots, avoiding subtracting large floating-point prefixes.
- Stop only after a complete event with C//3 >= P0-A, where C is the number of
  admitted nonoriginal active positions. This sufficient condition follows from
  each buffer weight being at least 1/sqrt(2) > 2/3.
- Restrict the new API explicitly to one original interval. Do not silently
  infer that the same bound holds for multiple components.
- Prove ideal arithmetic identities separately from rounded numerical results.
