# Bounded PR engine implementation plan

> **For agentic workers:** Use executing-plans for root tasks; independent baseline and submission tasks are delegated with disjoint files.

**Goal:** Test whether bounded compiled PR racing improves actual exact model-selection cost against equally specialized baselines.

**Architecture:** A PR-only curve kernel fills retained endpoint arrays. A compiled multi-model controller owns per-width scalar state, interval priorities and memory/work budgets; before a budget is exhausted it sweeps only unseen widths. Standalone sparse and direct dense PR baselines isolate adaptive gains.

**Tech Stack:** Python 3.10+, NumPy, optional Numba, pytest, existing public score corpus, TMLR LaTeX template.

**Spec:** docs/superpowers/specs/2026-10-21-pr-engine.md

## Global constraints

- Preserve metric semantics, tie tolerance 1e-10, order margin 3e-10, guard 1e-12.
- No repeated width evaluation; bounded retained curve storage; preparation timed.
- Existing 42 series are development; remaining 308 are adaptive holdout only.
- Record all outcomes, source/data hashes, aggregate time and regressions.
- No false external acceptance, authorship contribution or global SOTA claim.

## Review focus

- Merge boundaries and adjacent-versus-overlapping expanded ranges.
- Constant scores, large ties and almost-equal model maxima.
- Memory budget forcing immediate exact completion.
- Zero width, one detector, large width relative to series length.
- Fair PR-only comparison and source/data provenance.
